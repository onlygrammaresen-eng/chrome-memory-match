# Iconos de la extensión

Coloca aquí los siguientes archivos:

- `icon16.png`  (16×16)
- `icon48.png`  (48×48)
- `icon128.png` (128×128)

Puedes generarlos rápido en:
- https://favicon.io/favicon-generator/
- https://www.favicon-generator.org/
- O cualquier editor de imágenes (recomendado fondo azul + emoji 🧠)

Mientras no existan, Chrome usará un icono por defecto.
